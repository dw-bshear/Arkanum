# Arkanum 2026.1.1 release notes

Released October 8, 2026. This maintenance release includes first-run setup and vault-layout improvements from UI evaluation (issue #26).

## Changes

- Step 1 of first-run setup now spans the available page width, with improved recovery-key, button, and acknowledgment spacing.
- Removed "The route locks after an administrator exists" from the setup introduction. Setup still locks after the first administrator is created.
- Simplified recovery-key guidance to "Store the recovery key somewhere safe." Recovery-key requirements and loss warnings are unchanged.
- Moved Current access below Add login credential and Add secure note, retaining its styling and role-based controls.
- Reordered and renumbered vault section navigation to match the page for editable and read-only views.

## Installation and upgrade

Packages require ASP.NET Core Runtime 9 and a reachable SQL Server for durable deployment. Windows hosting uses IIS; Linux hosting uses systemd. See `upgrade-and-native-packaging.md` and `offline-package-checklist.md`.

Windows: extract the selected ZIP, open PowerShell as Administrator, and run `installers/windows/Install-ArkanumGui.ps1`.

Linux: extract the selected TAR.GZ, then run `python3 installers/linux/arkanum-gui-install.py` on a desktop, or use `installers/linux/install-arkanum.sh` with the documented environment settings.

For existing installations, back up the SQL database and matching Arkanum Recovery Key before upgrading. Run installer preflight first. Update mode preserves configuration, recovery/master-key material, database connectivity, and service bindings. This release adds no database migrations and does not require resetting setup or recreating vaults.
